# Simulations

Temporary instruments. **Dimensional consistency only.**

Allowed:

- Restate a manuscript number in SI and compare to a published range.
- Ampere-turn / B-field order-of-magnitude check for C-MAG-02.
- Solar-mean-density vs. C-FUS-05.

Not allowed:

- Vehicle mass budgets intended for construction.
- Chamber CAD or piston/valve sizing.
- Optimization of solenoid counts for a craft.
