# Literature fence

Allowed comparison targets for this archive. These papers and handbooks are **not** GCD sources.

## Planetary magnetic fields (C-PLN-01)

- Spacecraft-era equatorial / dipole compilations (Mercury, Earth, Jupiter, Saturn, Uranus, Neptune).
- IGRF / CHAOS-class models for Earth only.
- New Horizons non-detection language for Pluto; MESSENGER for Mercury; Cassini for Saturn; Juno for Jupiter.

Do not cite UFO or recovered-craft blogs as measured-B sources.

## High-field magnets (C-MAG-02, C-FUS-06)

Route magnet-capability questions to [Ra-Thor-HighTc-Superconductors](https://github.com/Eternally-Thriving-Grandmasterism/Ra-Thor-HighTc-Superconductors).

Allowed class of comparisons:

- REBCO / HTS tape magnets in the 10–20+ T class (laboratory and fusion-magnet programs).
- SPARC / CFS TF magnet public figures as *capability context*, not as a Černohajev build.

Forbidden: “they are building the 16.65 T saucer array at MIT.”
