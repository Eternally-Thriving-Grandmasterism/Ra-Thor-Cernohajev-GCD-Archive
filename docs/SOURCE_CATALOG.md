# Source Catalog

This catalog points at publicly presented items. It is not a dump of the manuscripts.

## Rights and citation

- Author of manuscripts: Valerijs Černohajev (also V.A. Černohaev), ~1980–2007; d. 2019.
- Public collection: [The Černohajev Archive — collection](https://cernohajev.omeka.net/collections/show/1)
- Editorial / translation notices associated with the public presentation should be respected. Quote sparingly. Do not treat this lattice as a rights holder of the 1980–2007 pages.
- Secondary critical-edition PDFs exist on third-party sites (e.g. engineeringinfinitybook.com). Prefer the Omeka item pages as the stable index.
- Collection identifier as published: `CARI-2025-001`. Publisher line: Černohajev Archive and Research Institute. Translation and analysis are separately copyrighted (© 2024 Gene Sticco, Natalja Černohajeva-Sticco, Mario Fialho), released for non-commercial scholarly citation with attribution. Cataloguing here relies on the item pages' own metadata and editorial summaries; it does not reproduce manuscript pages.

## Audit log — 2026-09-10

Checked every row for year, resolvable Omeka or edition path, and a one-line claim. Columns added in place; no new index file.

1. **Fixed:** VC-011–VC-014 carried the placeholder `collection index`. All four have stable item URLs (`items/show/11`–`14`) and belong to collection 1; only the collection landing page's first-ten pagination hid them.
2. **Open gap — per-work year.** All fourteen item pages publish the same Dublin Core `Date` (`circa 1980–2007`). No work can be dated individually from the public index. Do not attribute a specific year to a work until a primary page or edition front-matter supplies one.
3. **Open gap — edition path.** The 2024 translated edition is named in the collection `Relation` field, but no per-work pagination is published, so a row cannot yet cite an edition page range.
4. **Flag — VC-007 identifier.** The item page for Work No. 5 publishes no Dublin Core `Identifier` (every other manuscript item publishes `VC-0xx`). The label `VC-007` here is this lattice's sequence inference, not an archive-assigned identifier.
5. **Out of scope.** The archive also hosts items outside collection 1 — e.g. two 1986 Soviet program order forms (`CARI-T3-284`, `CARI-T3-285`) sourced from the George Knapp Thread III / Boris Sokolov material. These are not Černohajev GCD manuscripts, are not added as VC rows, and must not be merged into the claims register.

## How to add a source row

1. Prefer the Omeka item URL. `collection index` is not an acceptable value — resolve the item.
2. Fill all six columns. If year or edition pagination is genuinely unpublished, say so in the audit log rather than guessing.
3. Record identifier, language (Russian MS), presence of diagrams, and whether a critical-edition pagination exists.
4. Keep the one-line claim to one extractable assertion or number, sourced from the item page's own summary.
5. Do not paste multi-page transcriptions here.
